「爆款复刻」站内宣传方案

围绕"粘贴爆款链接 → AI 拆解 → 生成你的同款"这一核心卖点，在我们产品现有站内触点上完成首次大规模曝光与使用转化。本方案为 v1.0，覆盖目标、触点矩阵、激励设计、素材文案、上线节奏与实验设计。
版本 v1.0 阶段 上线预热 → 上线后 4 周 范围 站内（PC Web + 移动 H5） 日期 2026-10-08

结论先行（30 秒版）

  1. 一句话卖点：不用会拍、不用会剪——把刷到的爆款链接粘进来，就能得到一条自己的同款。宣传的核心不是讲功能，而是演示结果。
  2. 站内打法：上线周用「开屏一次曝光 + 首次免费旗舰体验」集中引爆，之后靠「意图识别推荐 + 生成完成页交叉引流」沉淀为常态化入口，4 周内完成从活动到习惯的过渡。
  3. 关键钩子：首次复刻免积分（限一次、旗舰模型、带防刷约束），让用户零成本体验完整 S1→S5 链路——出片那一刻就是付费动机产生的那一刻。
  4. 两条红线：① 宣传素材必须用真实生成结果，禁止过度承诺画质与耗时；② 活动元素全部可关闭、到期自动撤除，不与产品"极简、无常驻打扰"的原则冲突。
  5. 胜负手指标：不是曝光量，而是触点点击 → 进入 S1 → 完成出片（S5）的转化率，以及出片用户的 7 日内二次复刻率。

2用户分层与差异化话术

同一功能，对不同存量用户的价值主张不同；全量一套文案是最常见的浪费。

3.3 关键决策：首曝形式 A/B

方案 A：全屏弹窗（强制互动）

  • 曝光完成度高，点击率通常更高
  • 打断感强，与产品极简原则冲突
  • 用户可能直接关闭并产生负面印象

方案 B：开屏 3 秒可跳过 推荐

  • 曝光完成度同样高（3 秒内自动播放演示）
  • 可跳过 = 不打扰，符合产品"无常驻打扰"原则
  • 每账号仅展示 1 次，稀缺感反而提升点击
推荐 B。首曝的目的是"让用户看见结果长什么样"，3 秒动态演示已经完成传达；强制互动带来的打扰成本在 AI 工具用户中口碑代价偏高。上线后若 B 的 CTR 低于预期下限，再考虑 A/B 对照实验验证。

4激励设计：首次免费 + 任务解锁

复刻是积分消耗场景（生成 3–8 分钟、多模型计价），激励设计的本质是用一次受控的免费体验换取付费动机，同时守住防刷底线。

4.1 免费额度结构 A/B

方案 A：首次全免（任意模型 30s）

  • 体验最完整，出片效果最好
  • 单次成本最高（旗舰模型 + 30s）
  • 被批量注册薅羊毛的风险最大

方案 B：旗舰一次 + 任务解锁第二次 推荐

  • 第一次：免费用旗舰模型出一条 15–30s 成片（完整体验 S1→S5）
  • 第二次：完成轻任务解锁（如成功分享一次 / 完成新手指引）
  • 总成本可控（户均 ≤ 2 次），且第二次附带传播或留存动作
推荐 B。第一次必须给旗舰体验——如果免费额度只给低成本模型（如耗时 6 分钟的入门档），"生成慢 + 效果平"的第一印象会直接杀死复购意愿；但无上限的全免不可接受。两次封顶 + 任务解锁是体验与成本的平衡点。

4.2 防刷约束（与商业护栏指标联动）

约束规则
账号限制免费额度每账号（非每设备）限 2 次，需完成手机号绑定
设备指纹同设备多账号领取时仅首个账号生效
频次监控单账号 24h 生成次数、同 IP 多账号行为进入风控阈值（与 PRD 评审建议的护栏指标同一套）
异常处置命中风控的账号免费额度冻结，人工复核后恢复
红线：免费活动上线前，风控阈值必须先于活动生效——先开闸再补门等于直接给羊毛党发钱。这条作为活动上线的硬性前置条件。

5宣传素材与文案

文案原则：只承诺可以兑现的；用结果演示代替功能罗列；数字表述克制（"听听就好"风格，不绝对化）。

5.1 主文案 A/B

方向 A：功能说明型

  • 「全新爆款复刻功能上线：AI 拆解爆款结构，一键生成你的同款视频」
  • 信息完整，但像产品说明书
  • 用户需要自己翻译成"关我什么事"

方向 B：场景共鸣型 推荐

  • 主标题：「刷到爆款，想想就好？粘个链接，就是你的」
  • 副标题：「不用会拍、不用会剪——AI 拆完结构，直接给你一条能用的同款」
  • 命中"这条我能拍 → 但做不到"的真实心理落差
推荐 B。目标用户的卡点不是"不知道有这个功能"，而是"觉得做视频这件事很难"。文案要卖的是"你也行"，不是"功能很全"。

5.2 分层文案速查

高活跃创作者
「爆款的结构，AI 30 秒拆完。改成你的版本，不用从零开始。」
低活跃 / 沉睡用户
「这次真的不用你会做视频——粘个链接试试，第一次免费。」
新用户（onboarding）
「三个能力里最简单的一个：把你喜欢的视频，变成你自己的。」
开屏 / Banner（结果演示型）
双屏自动播放：左「别人的爆款」→ 右「你的同款」，角标「首次免费」。

6上线节奏（T-7 → T+28）

以功能上线日为 T0；前置项与 PRD 评审的开放问题闭环节奏对齐。

T-7 · 预热
站内公告「新功能预告」+ 预约入口（预约用户上线时优先获得免费额度）；素材三套演示进入制作与内部走查；埋点方案评审。
T-3 · 就绪检查
硬性前置条件确认：埋点就绪 ✓ / 风控阈值生效 ✓ / 免费额度后台配置 ✓ / 素材双端适配 ✓。任一未就绪则整体顺延，不裸奔上线。
T0 · 上线引爆
开屏 + Banner + 金刚位 + 站内信同日上线；免费额度生效；首日盯漏斗实时数据（触点 CTR、S1 进入量、生成队列负载）。
T+1 ~ T+7 · 引爆周
按触点 CTR 数据调整素材（保留最优、替换最差）；Chat 意图推荐与完成页交叉推荐灰度放量；每 2 天输出一次漏斗简报。
T+7 ~ T+14 · 案例与传播
征集用户优秀复刻作品（授权后进入案例库与素材中心）；「复刻挑战」轻活动：晒成片赢积分。
T+14 ~ T+28 · 常态化
活动元素按计划撤除（开屏下线、Banner 降位）；金刚位与场景化推荐成为长期入口；输出 4 周复盘：渗透率、完成率、二次复刻率、积分消耗结构、免费额度成本与防刷命中。

7实验设计

上线期只做必要的对照实验，避免同时改动过多变量。

实验分组主指标判定
E1 开屏素材存钱 vs 美食 vs 穿搭三套演示轮播分组开屏 → S1 点击率CTR 差异 ≥ 20% 保留最优，否则混用
E2 主文案场景共鸣型 vs 功能说明型（Banner 位）Banner CTR差异不显著则固定用 B
E3 免费额度「旗舰一次」vs「旗舰一次 + 任务解锁第二次」7 日二次复刻率 / 成本二次复刻率提升覆盖额外成本则保留任务版
E4 Chat 推荐意图触发 vs 意图 + 每周一次轻推送卡片点击率 / 负反馈率（关闭、屏蔽）负反馈率上升超阈值即回收轻推送

8风险与克制原则

⛔ 过度打扰

  • 开屏每账号仅 1 次；活动弹层可关闭且记住选择
  • Chat 推荐有频控（同一用户每周 ≤ 2 次）
  • 活动结束所有临时元素自动撤除，不留常驻残留

⛔ 薅羊毛

  • 免费额度封顶 2 次 / 账号 + 手机绑定 + 设备指纹
  • 风控阈值先于活动上线
  • 异常频次监控接入每日复盘简报

⛔ 承诺落差

  • 素材全部真实生成，禁用"媲美原片 / 30 秒出片"类表述
  • 生成耗时统一用"几分钟"量级表述
  • 匹配度评分宣传中不使用具体分值示例

⛔ 生成容量

  • 免费体验集中涌入会冲击生成队列（单次 3–8 分钟）
  • 上线首日与压测联动，必要时免费额度分批放量
  • 队列过载时优先保付费用户体验
